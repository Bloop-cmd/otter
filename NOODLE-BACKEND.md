# Noodle backend hook

The demo contains a tiny `Noodle` adapter in `index.html`.

It is intentionally a mock adapter:
- `Noodle.connect()`
- `Noodle.save(event, payload)`

Current demo events:
- `dive.activated`
- `status.updated`
- `group.created`

Replace these methods with the real Noodle SDK/API once the backend endpoint/schema is available. No credentials are included in the demo.
