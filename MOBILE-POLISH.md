# Otti V4 — Mobile Chat Polish

This version tightens the WhatsApp-style chat experience for small screens.

Key mobile behavior:
- Full-width, compact chat header and message area.
- Fixed bottom composer with safe-area padding.
- `〰 DIVE` stays immediately beside the Send control.
- Composer controls shrink gracefully at <=380px widths.
- Horizontal filter chips scroll instead of wrapping into awkward rows.
- Chat rows use compact WhatsApp-like spacing and ellipsis previews.
- Doodles remain decorative and never intercept taps.
